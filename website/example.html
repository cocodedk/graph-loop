The gate

A command, nothing more. Its exit code is the verdict, and the loop proves it fails before anyone is allowed to make it pass.

set -e -o pipefail
TMPD=$(mktemp -d)
javac -d "$TMPD" app/src/main/java/dk/cocode/xpost/PostLink.java \
                 app/src/test/java/dk/cocode/xpost/PostLinkTest.java
java -cp "$TMPD" dk.cocode.xpost.PostLinkTest
